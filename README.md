After installing our application, you need to right-click the .exe file and select "Run as administrator"; please ensure Steam is already open before launching the app. Once the application is open, a large box in the bottom-left corner will display the games installed on your system; double-clicking one of these will show the names and status (unlocked/locked) of its achievements in the large central box. You can unlock or lock all achievements using the controls located above that section. The button next to the "Unlock/Lock" controls indicates the connection status to Steam; you do not need to interact with it. If you wish to unlock achievements for a game that is not currently installed, you can manually visit the SteamDB website, copy the desired game's App ID, paste it into the "Enter App ID" box, and add it; the added game will appear in the list below, and you can then unlock its achievements by clicking on it. Additionally, double-clicking a game in the list makes it appear as though you are currently playing it, allowing you to farm playtime hours. Have a nice day, and thank you.
